================================================================================
                           ORENDA API SPECIFICATION
================================================================================

API Title: Orenda API
Description: Turkey-focused "Travel Operating System" — Spring Boot backend.
             POI discovery/search, weather, routing, trip planning, user 
             preferences, profile onboarding, and data-import triggers.
Version: 0.0.1-SNAPSHOT
Contact: Orenda

================================================================================
                                SERVERS
================================================================================

1. Deployed server url 
   URL: https://orenda-d9qj.onrender.com

================================================================================
                                 TAGS
================================================================================

1. Auth
   Description: User management, JWT, email verification, Google OAuth

2. POI
   Description: Point-of-interest discovery, search, categories, feedback

3. Weather
   Description: Current conditions + daily forecast (Open-Meteo)

4. Routing
   Description: Point-to-point routing (OSRM)

5. Trip Planner
   Description: Ranked POI suggestions and day-by-day trip plans

6. Preferences
   Description: Learned per-category preference weights and feedback

7. Profile
   Description: Long-term traveler onboarding profile

8. Imports
   Description: Manually trigger background data-import jobs

Security: No global security (varies per endpoint)

================================================================================
                               DATA SCHEMAS
================================================================================

AUTH SCHEMAS
------------

SignupRequest:
  - email: string (email format) [REQUIRED]
  - password: string (min 6, max 72) [REQUIRED]
  - fullName: string (max 200)

LoginRequest:
  - email: string (email format) [REQUIRED]
  - password: string [REQUIRED]

ResendVerificationRequest:
  - email: string (email format) [REQUIRED]

UserResponse:
  - id: string (UUID)
  - email: string
  - fullName: string (nullable)
  - emailVerified: boolean
  - authProvider: enum [LOCAL, GOOGLE]
  - createdAt: date-time

SignupResponse:
  - user: UserResponse
  - emailSent: boolean
  - message: string

VerifyEmailResponse:
  - verified: boolean
  - user: UserResponse

AuthResponse:
  - token: string
  - tokenType: string (example: Bearer)
  - user: UserResponse

AuthProvider: enum [LOCAL, GOOGLE]

ApiError:
  - status: int32
  - code: string (example: VALIDATION_ERROR)
  - message: string

POI SCHEMAS
-----------

PoiResponse:
  - id: string (UUID)
  - osmId: int64
  - osmType: string (nullable)
  - nameTr: string (nullable)
  - nameEn: string (nullable)
  - category: string (nullable)
  - subcategory: string (nullable)
  - lat: double
  - lon: double
  - completenessScore: int32
  - distanceKm: double (nullable) - Present only in /nearby results
  - attributes: object (nullable)

FeedbackType: enum [CLOSED, INACCURATE, MOVED, DUPLICATE, OTHER]

FeedbackRequest:
  - poiId: string (UUID) [REQUIRED]
  - type: FeedbackType [REQUIRED]
  - details: string (nullable)
  - sessionId: string (nullable)
  - newLat: double (nullable) - Only for MOVED
  - newLon: double (nullable) - Only for MOVED

FeedbackResponse:
  - accepted: boolean
  - message: string
  - alternativePoi: PoiResponse (nullable)

WEATHER SCHEMAS
---------------

WeatherResponse:
  - location: WeatherLocation
  - current: CurrentConditions
  - daily: array of DailyForecast

WeatherLocation:
  - latitude: double
  - longitude: double
  - timezone: string

CurrentConditions:
  - temperature: double
  - feelsLike: double
  - humidity: int32
  - windSpeed: double
  - windDirection: int32
  - weatherCode: int32
  - description: string

DailyForecast:
  - date: date
  - maxTemp: double
  - minTemp: double
  - precipitation: double
  - maxWindSpeed: double
  - weatherCode: int32
  - description: string

ROUTING SCHEMAS
---------------

RouteResponse:
  - distanceKm: double
  - durationMinutes: double
  - profile: enum [driving, foot, bike]
  - summary: string
  - geometry: object (GeoJSON LineString)

TRIP PLANNER SCHEMAS
--------------------

TripPlanRequest:
  - basics: TripBasics [REQUIRED]
  - profile: TripTravelerProfile [REQUIRED]
  - interests: TripInterests [REQUIRED]
  - style: TripTravelStyle [REQUIRED]
  - sessionId: string (nullable)

TripBasics:
